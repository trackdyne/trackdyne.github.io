## KEY FEATURES

* **Minimum dimensions and weight**
* **Splash-proof design**

## DESCRIPTION

The device is designed to connect [SubVox Diver](/documentation/EN/SubVox/SubVox_Diver_Specification_en.html) devices to a PC for configuration purposes.

<div style="page-break-after: always;"></div>

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (L x W x H, excluding the cable) | 42 x 26 x 109 mm |
| USB CABLE LENGTH | At least 0.1 m |
| WEIGHT | 110 g |
| OPERATING TEMPERATURE RANGE | -10 .. 50 °C |
| MAXIMUM RADIO COMMUNICATION RANGE<sup>[1](#footnote1)</sup> | 30 m |
| CONNECTION | To a PC's USB port |
| MOUNTING | Magnetic |

________________
<a name="footnote1"><sup>1</sup></a> Achieved in the absence of interference, in an open area.
