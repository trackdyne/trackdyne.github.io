## KEY FEATURES

* **IP68 protection class**
* **GNSS receiver protocol emulation**
* **Built-in GNSS module**

## DESCRIPTION

The navigation buoy signal receiver of the **[EchoTrace](/documentation/EN/EchoTrace/EchoTrace_DataBrief_en.html)** system receives signals from the [EchoTrace GIB](/documentation/EN/EchoTrace/EchoTrace_GIB_Specification_en.html) navigation buoys and determines the location of the underwater object on which the [EchoTrace Pinger](/documentation/EN/EchoTrace/EchoTrace_Pinger_Specification_en.html) pinger is located. The receiver is a maintenance-free monoblock on a cable.

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (Ø x h, w/o cable) | 90 x 330 mm |
| WEIGHT (w/ 10 m cable) | 1.4 kg |
| CABLE LENGTH | 10 m |
| CABLE DIAMETER | 10 ± 0.5 mm |
| OPERATING TEMPERATURE RANGE | -10 .. 50 °C |
| MAXIMUM RADIO COMMUNICATION RANGE<sup>[1](#footnote1)</sup> | 1000 m |
| RADIO COMMUNICATION | 433 MHz, receive only |
| CONNECTION | To a PC USB port via [VigilArc Deck](/documentation/EN/VigilArc/VigilArc_Deck_Specification_en.html) |
| INTERFACE | RS-422, 38400 baud |
| PROTOCOL | [NMEA0183 (GGA, RMC), UNV](/documentation/EN/EchoTrace/EchoTrace_RF_Dongle_Protocol_Specification_en.html) |
| BUILT-IN GNSS module | GPS/GLONASS |
| HOUSING MATERIAL | Polyurethane |

________________
<a name="footnote1"><sup>1</sup></a> Achieved in the absence of interference, in open areas.
