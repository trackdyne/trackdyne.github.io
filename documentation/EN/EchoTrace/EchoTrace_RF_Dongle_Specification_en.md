## KEY FEATURES

* **IP68**
* **GNSS protocol emulation**
* **Built-in GNSS receiver**

## DESCRIPTION

The receiver of the navigation signal of the buoys of the system [EchoTrace](EchoTrace_DataBrief_en.md) receives signals from the [EchoTrace GIB](EchoTrace_GIB_Specification_en.md) navigation buoys and determines the location of the underwater object on which the [EchoTrace Pinger](EchoTrace_Pinger_Specification_en.md) pinger is located. The receiver is designed as a maintenance-free monoblock on a cable.

## TECHNICAL SPECIFICATIONS

| PARAMETER | VALUE |
| :--- | :--- |
| DIMENSIONS (Ø x h, w/o cable) | 90 x 330 mm |
| WEIGHT (w/ 10 m cable) | 1.4 kg |
| CABLE LENGTH | 10 m |
| CABLE DIAMETER | 10 ± 0.5 mm |
| WORKING TEMPERATURE RANGE | -10 .. 50 °C |
| MAX. RF RANGE<sup>[1](#footnote1)</sup> | 1000 m |
| RADIO COMMUNICATION | 433 MHz, receiving only |
| CONNECTION | to a PC USB-port via [VigilArc Deck](/documentation/EN/VigilArc/VigilArc_Deck_Specification_en) |

| PROTOCOL | [NMEA0183 (GGA, RMC), UNV](/documentation/EN/EchoTrace/EchoTrace_RF_Dongle_Protocol_Specification_en.md) |
| BUILT-IN GNSS UNIT | GPS/GLONASS |
| BODY MATERIAL | Polyurethane |
